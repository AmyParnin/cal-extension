This extension works without an API key. Without one, event titles are generated using a built-in date/time parser. Add a Claude API key to get smarter, AI-generated titles that better summarise the highlighted text.
How to get your Claude API key:
1. Go to console.anthropic.com/settings/keys
2. Click Create Key — choose Standard (not identity-linked)
3. Paste the key above and click Save

If you have an identity-linked key, also paste your Workspace ID (find it at console.anthropic.com/settings/workspaces).

Your key is stored only in this browser and never shared. New accounts include free credits — typical use costs <$0.01/month.
